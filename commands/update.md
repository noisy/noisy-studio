---
description: Update the Noisy Studio app and companion plugin
---

Update the native app from the project's GitHub releases and update the
`noisy-coding` plugin through the host's plugin manager. Both must support the
same release's integration entry points. Keep user configuration and history.

Start a new coding session after updating. Check the running app version,
ask the agent to speak, reply aloud, and verify both messages use the intended
tab. Do not declare success based only on downloaded assets or plugin files.
Use `docs/INSTALL.md` for troubleshooting. Publishing a release is a separate,
explicitly authorized task.

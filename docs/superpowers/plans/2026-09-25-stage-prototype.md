# Stage prototype

Build a Storybook-only app-content Stage for all open conversations. Reuse VoiceAvatar and existing artwork. Default to heads and names in a stable irregular constellation. Speaking changes add visual emphasis without rearranging positions. Individual hiding and local focus never route the microphone. Optional current-caption and shared-transcript views are visual experiments, not shared agent context or facilitation. Keep offline and muted participants visibly distinct.

Implement an isolated presentational Stage component, fixture stories for 1/3/6/many/empty/offline/muted/long labels/reduced motion, and focused interaction tests. Verify type/build checks and screenshots on desktop and narrow screens. No production dashboard, daemon, or live settings changes.
